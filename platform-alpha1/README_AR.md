# HDB Hospitality OS — Alpha 1

هذه بداية إعادة بناء منصة HDB كنظام Hospitality حقيقي، مع الإبقاء على تطبيق التلفزيون القديم بدون تعديل داخل هذا الفرع.

## ما تم تنفيذه

- مركز قيادة عربي RTL متجاوب.
- مؤشرات الإشغال والتلفزيونات والقنوات والطلبات.
- خريطة مباشرة للغرف مع فلترة بالأدوار.
- جدول الغرف والإقامات مع البحث والفلترة.
- مراقبة تجريبية لحالة PMS وWISI والأجهزة والقنوات.
- محرر أولي لشاشة الترحيب مع معاينة تلفزيون مباشرة.
- تنقل كامل بين أقسام النظام.
- REST JSON API أولي للغرف والأجهزة والقنوات والطلبات والرسائل والإعدادات.
- تخزين JSON آمن بالكتابة الذرية بدل الاعتماد على SQLite.

## التشغيل

ضع مجلد `platform-alpha1` داخل مجلد الويب في XAMPP، مثال:

```text
C:\xampp\htdocs\HDBIPTV\platform-alpha1
```

ثم افتح:

```text
http://localhost/HDBIPTV/platform-alpha1/
```

اختبار API:

```text
http://localhost/HDBIPTV/platform-alpha1/api/?resource=health
http://localhost/HDBIPTV/platform-alpha1/api/?resource=rooms
```

## متطلبات السيرفر

- PHP 8.0 أو أحدث.
- صلاحية كتابة على مجلد `storage`.
- Apache أو Nginx.

## نطاق Alpha 1

Alpha 1 يثبت شكل المنصة والبنية الأساسية. البيانات المعروضة في الواجهة تجريبية حاليًا، بينما API يعمل كطبقة CRUD أولية. الربط الكامل بين الواجهة وAPI، المصادقة، الصلاحيات، سجل العمليات، وربط تطبيق التلفزيون تأتي في المراحل التالية.

## الفرع

```text
build/hospitality-alpha1
```
